Windows, macOS ve iOS'ta SOCKS5 Proxy Nasıl Kurulur

18 Eylül 2026'da yayınlandı

Tether Link Utility, Android telefonunuzda yerel bir SOCKS5 proxy çalıştırır. SOCKS5 proxy ayarlarını destekleyen herhangi bir cihaz, telefonun kendi Wi-Fi hotspot'u üzerinden buna bağlanabilir, Windows veya macOS'ta ayrı bir istemci uygulaması gerekmez, iOS'ta hafif bir tane gerekir. İşte her platformu buna yönlendirmenin tam yolu.

Başlamadan önce

Tether Link Utility'yi açın, START SERVER'a dokunun ve ekranda gösterilen iki şeyi not edin: IP adresi ve port. Aşağıda cihazınıza uyan kurulumun hangisi olursa olsun ikisini de gireceksiniz.

Windows

Seçenek A: Firefox (eklenti gerekmez)

  1. Settings → General → Network Settings → Settings'e gidin.
  2. Manual proxy configuration'ı seçin.
  3. Telefonun IP'sini SOCKS Host'a, portu Port'a girin ve SOCKS v5'i seçin.
  4. Tünel dışına DNS sızıntısını önlemek için Proxy DNS when using SOCKS v5'i işaretleyin.

Seçenek B: Chrome veya Edge, FoxyProxy ile

  1. Chrome Web Store'dan FoxyProxy eklentisini kurun.
  2. Yeni bir proxy ekleyin: tür SOCKS5, host = telefonun IP'si, port = uygulamada gösterilen port.
  3. Araç çubuğu simgesinden FoxyProxy'yi bu proxy'ye geçirin.

Seçenek C (önerilen): sing-box ile tam sistem kapsaması

Firefox ve FoxyProxy sadece o tek tarayıcının trafiğini yönlendirir, DNS sorguları ve arka plan uygulama trafiği düz hotspot bağlantısı üzerinden korumasız çıkabilir. Windows'ta DNS dahil her uygulamanın tünellenmesi için bunun yerine TUN modunda sing-box kullanın (açık kaynak, MIT'ye yakın lisans, aktif olarak sürdürülüyor):

  1. github.com/SagerNet/sing-box/releases'ten en son Windows sürümünü indirin.
  2. Aşağıdaki yapılandırmayı config.json olarak kaydedin, IP/portu uygulamada gösterilenle değiştirin.
  3. Yükseltilmiş (Yönetici) bir terminalden çalıştırın: sing-box run --config config.json

macOS

Seçenek A: yerleşik Network ayarları

  1. System Settings → Network'ü açın.
  2. Bağlı olduğunuz Wi-Fi ağını (telefonun yayınladığı) seçin ve Details…'a tıklayın.
  3. Proxies'e gidin, SOCKS Proxy'yi işaretleyin.
  4. Telefonun IP adresini ve portunu girin, ardından OK → Apply'a tıklayın.

Üçüncü taraf bir uygulama gerekmez, ama macOS'un yerleşik SOCKS ayarının DNS'i proxy üzerinden yönlendirmediğini unutmayın, yani gezinme trafiğiniz sızmasa bile DNS sorguları tünel dışına sızabilir.

Seçenek B (önerilen): sing-box ile tam sistem kapsaması

Her şey için, her uygulama için, DNS dahil, yukarıdaki yerleşik ayar yerine sing-box'ı TUN modunda çalıştırın.

En kolay yol: wrapper script'imizi indirin, Homebrew'u kontrol eder, gerekirse sing-box'ı kurar, telefonunuzun IP ve portunu sorar ve her şeyi arka planda çalıştırır (Terminal penceresi küçülür, sadece bir sorun çıkarsa geri gelir).

tlu-mac-tunnel.zip indir

Açın, sonra Terminal'de: chmod +x tlu-mac-tunnel.sh && ./tlu-mac-tunnel.sh

Gerçekten çalışıyor mu? İşte kanıtı

Script'i çalıştırdık, tünel üzerinden 1GB'lık bir test dosyası indirdik ve öncesinde/sonrasında telefonun operatör hesabını kontrol ettik. Hotspot paylaşım veri paketi her iki seferde de aynı kalan miktarı gösterdi, hiçbir şey ondan düşülmedi, uygulamanın kendi sayacı tünel üzerinden 1GB'ın çok üzerinde bir aktarım gösterse bile.

Gösterilen operatör hesabı Vodafone, tam Vodafone hotspot veri açıklamasına bakın.

Ya da elle kurun:

  1. Homebrew ile kurun: brew install sing-box
  2. Aşağıdaki yapılandırmayı ~/config.json olarak kaydedin, IP/portu uygulamada gösterilenle değiştirin.
  3. Çalıştırın (sudo gerektirir, sanal bir ağ arayüzü oluşturur ve yönlendirmeyi değiştirir): sudo sing-box run --config ~/config.json
  4. Açıksa Seçenek A'daki yerleşik SOCKS Proxy ayarını kapatın, sing-box'ın TUN modu onun yerini tamamen alır.

sing-box yapılandırması (hem Windows hem macOS için çalışır, sadece IP/portu değiştirin). interface_name'i boş bırakın, otomatik olarak uygun bir arayüz seçsin:

{
  "dns": {
    "servers": [
      { "type": "udp", "tag": "remote", "server": "8.8.8.8", "detour": "phone-socks5" },
      { "type": "local", "tag": "local", "detour": "direct" }
    ],
    "final": "remote"
  },
  "inbounds": [
    { "type": "tun", "tag": "tun-in", "address": ["172.19.0.1/30"], "mtu": 1500,
      "auto_route": true, "strict_route": true, "stack": "system" }
  ],
  "outbounds": [
    { "type": "socks", "tag": "phone-socks5", "server": "PHONE_IP", "server_port": PHONE_PORT, "version": "5" },
    { "type": "direct", "tag": "direct" }
  ],
  "route": {
    "rules": [ { "ip_cidr": ["PHONE_IP/32"], "outbound": "direct" } ],
    "final": "phone-socks5",
    "auto_detect_interface": true,
    "default_domain_resolver": "remote"
  }
}

PHONE_IP ve PHONE_PORT'un ikisini de uygulamada gösterilen değerlerle değiştirin (ve PHONE_IP/32 route kuralını da, o satır tünelin kendi telefon bağlantısını yine kendisi üzerinden yönlendirmeye çalışmasını önler). Gerçek bir operatöre karşı doğrulandı, QUIC/HTTP3 ve DNS ikisi de uygulamanın bunun için özellikle SOCKS5 UDP ASSOCIATE desteği eklenen son sürümünde doğru şekilde tünelleniyor.

iOS

Seçenek A: Shadowrocket (ücretli, tek seferlik satın alma)

  1. Shadowrocket'i açın ve sağ üstteki + butonuna dokunun.
  2. Socks5 türünü seçin.
  3. Telefonun IP'sini adres, uygulamada gösterilen portu port olarak girin.
  4. Kaydedin, sonra bağlanmak için üstteki düğmeye dokunun.

Seçenek B: Potatso Lite (ücretsiz)

  1. Potatso Lite'ı açın ve yeni bir proxy profili ekleyin.
  2. SOCKS5'i seçin, IP ve portu girin, kaydedin.
  3. iOS istediğinde VPN profilini etkinleştirin, Potatso trafiği SOCKS5 proxy üzerinden bu şekilde yönlendirir, çünkü iOS'ta macOS'taki gibi yerleşik bir SOCKS5 ayarı yok.

DNS ipucu: Her platformda, seçenek varsa DNS sorgularının da proxy üzerinden yönlendirildiğinden emin olun (Firefox'un "Proxy DNS when using SOCKS v5"ı, Shadowrocket'in varsayılan davranışı). Aksi halde gerçek trafiğiniz sızmasa bile DNS sorguları tünel dışına sızabilir, yukarıdaki sing-box'ın TUN modunun yapı gereği önlediği tam olarak bu, çünkü her uygulamanın ayrı ayrı katılmasına güvenmek yerine DNS'i her şeyle birlikte yakalar.

Android'den Android'e daha basit

Her iki cihaz da Android ise, yukarıdakilerin hepsini atlayın, istemci telefonda QR Kodu Tara · Sunucuya Bağlan'a dokunun ve kamerayı sunucu telefonda gösterilen QR koduna doğrultun. Çoğu cihazda Wi-Fi ve proxy bağlantısı tek dokunuşla tamamlanır.
