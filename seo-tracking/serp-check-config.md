each time. Append new dated result files under `serp-checks/`, don't edit past ones.

## Methodology
- Domain tracked: `tetherlinkutility.com`
- Search executed via the WebSearch tool, 10 keywords per batch, 10 batches (parallel calls within
  each batch).
- **Caveat:** WebSearch returns a curated ~9-link result set plus a synthesized summary per query —
  not a full paginated Google SERP. "Appeared: N" means the domain wasn't in that curated set, not
  a confirmed rank beyond position ~9. Treat results as a directional signal, not a precise rank
  report. For precise positions, use Google Search Console (not yet set up as of 2026-09-18 — no
  `google-site-verification` covering this check, and no GSC property confirmed).
- First run: 2026-09-18, generated and executed by a forked agent within a Claude Code session.
